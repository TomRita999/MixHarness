# 与 AI 共享一个窗口

在 macOS 14.2 或更新版本上，可以把一个可见窗口共享给当前 MixHarness 会话。Gemini 或 GPT 直聊和 GPT 工程任务可以按需读取截图。例如，在打开文档的窗口上选择「仅查看」，然后问 Gemini「这页列出了哪些交付条件？」。

## 在桌面端共享

1. 点输入框旁的 **＋ → 与 AI 共享窗口…**。首次使用时，在系统设置的「隐私与安全性」中授权屏幕录制，回到选择框后点「刷新窗口」。
2. 选中目标窗口。默认的「仅查看」允许按需截图。需要点击、输入、滚动或使用快捷键时，选择「允许操作」，并授予 macOS 辅助功能权限。
3. 点「共享所选窗口」。输入框上方会显示应用、窗口标题和共享权限。选好 Gemini 或 GPT 后，直接描述要完成的操作。点「停止共享」可以撤销本次绑定。

从源码运行时，首次使用会通过 Xcode Command Line Tools 编译原生辅助程序，需要包含 ScreenCaptureKit 的 macOS 14.2 或更新 SDK。macOS 桌面打包流程会把辅助程序放入应用。

## 从命令行共享

在同一会话库的桌面端或 `mixharness serve` 运行期间，使用以下命令。`SESSION_ID` 是会话编号，`TARGET` 是 `window list` 返回的目标编号。需要指定会话库时，在 `window` 前传入 `--library 目录` 和对应的 `--data-dir 目录`。

```sh
mixharness window permissions
mixharness window list
mixharness window bind SESSION_ID TARGET
mixharness window status SESSION_ID
mixharness window stop SESSION_ID
```

绑定时加 `--control` 允许模型操作所选窗口。`mixharness window permissions screen` 和 `mixharness window permissions accessibility` 可分别发起系统权限请求。

## 窗口权限与会话审批

| 会话权限 | 读取截图 | 已选择「允许操作」时的点击、输入、滚动、快捷键 |
| --- | --- | --- |
| `ask` | 每次请求批准 | 每次请求批准 |
| `auto` | 自动批准 | 每次请求批准 |
| `full` | 自动批准 | 自动批准 |

三档都需要用户先绑定窗口。「仅查看」始终只开放截图。模型收到的是所选窗口的实际图像。MixHarness 在引擎内存中暂存当前画面，工具回执保存画面编号和尺寸。截图会发送给当前使用的模型后端。

每次操作引用本任务最近一次截图的编号，编号最长有效五分钟，执行一次操作后就失效。窗口移动或调整大小后需要重新截图。点击和滚动只作用于能够确认属于该窗口的辅助功能控件。输入和快捷键要求焦点位于共享窗口，支持的快捷键为 `Cmd+A`、`Home`、`End`、`Return` 和 `Space`。受保护的密码框以及未提供相应辅助功能动作的控件会拒绝操作。

停止共享、更换目标或重启引擎都会使旧绑定失效。分支会话需要单独选择窗口。

## 隔离验证

`python-compile` 和 `python-tests` 在项目快照中运行。`tests/test_window_entrypoints.py` 创建两个独立的会话库与数据目录，通过各自的本地随机端口检查 CLI 路由和服务锁。`tests/test_window_actions.py` 只向本次测试创建的 AppKit 窗口发送操作，并读取控件的实际状态来核验结果。测试会查询已有的系统授权，缺少授权时，日志会标明跳过的实机项目。
