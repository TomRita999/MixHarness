# 与 AI 共享窗口或桌面

在 macOS 14.2 或更新版本上，可以为当前会话选择一个窗口，也可以共享整个桌面。Gemini 和 GPT 直聊、GPT 工程任务均可使用用户授予的范围。每个会话单独授权，默认关闭。

## 桌面端入口

1. 在输入框旁点 **＋ → 与 AI 共享窗口…**。首次使用时，授予 macOS 屏幕录制权限，然后点「刷新窗口」。
2. 选择具体的窗口，或选择「整个桌面 · 所有显示器与应用窗口」。默认「仅查看」。需要鼠标或键盘输入时，选择「允许操作」，并授予 macOS 辅助功能权限。读取辅助功能树也需要这项系统权限。
3. 点「共享所选窗口」或「共享整个桌面」。输入框上方会显示当前共享范围与权限。点「停止共享」即可撤销。

从源码运行时，首次使用会通过 Xcode Command Line Tools 编译辅助程序，需要包含 ScreenCaptureKit 的 macOS 14.2 或更新版本 SDK。macOS 桌面发行包随附编译好的辅助程序。

## 两种共享范围

**单个窗口**适合让模型读取一份文档或操作指定应用中的一个表单。「仅查看」开放窗口截图。「允许操作」还支持操作辅助功能控件、输入文字、滚动和 `Cmd+A`、`Home`、`End`、`Return`、`Space`。输入和快捷键要求焦点属于所选窗口。

**整个桌面**允许模型发现显示器、应用和窗口。模型先调用 `computer_list` 获取目标编号，再用 `computer_capture` 读取一块显示器的全屏截图或指定窗口的截图。`computer_inspect` 读取指定窗口的辅助功能树，选择显示器时读取与该显示器相交的前台焦点窗口。应用提供的辅助功能信息决定能读到哪些控件。`computer_wait` 可等待界面更新。

开启桌面的「允许操作」后，模型可以激活窗口、单击、双击、拖拽、输入文字、水平或垂直滚动，以及使用组合快捷键。例如，可以让模型在两个应用窗口间切换，填写表单后重新截图检查结果。坐标以最近截图左上角为原点。每次输入需引用当前任务、当前目标的画面编号，操作后需要重新截图。

## 会话审批

| 会话权限 | 读取截图、发现目标、读取控件和等待 | 已开启「允许操作」时的窗口激活、鼠标和键盘操作 |
| --- | --- | --- |
| `ask` | 每次审批 | 每次审批 |
| `auto` | 自动批准 | 每次审批 |
| `full` | 自动批准 | 自动批准 |

三档权限均受用户选定的共享范围和 macOS 系统授权约束。模型收到选定目标的实际截图。引擎在内存中暂存最近的画面，画面编号最长有效五分钟。停止共享、更换共享目标或重启引擎会使授权失效，分支会话需要重新选择。

## 命令行入口

在桌面端或 `mixharness serve` 已打开相应会话库时运行以下命令。`SESSION_ID` 为会话编号，`TARGET` 为 `window list` 返回的窗口编号。需要指定会话库时，在 `window` 前传入 `--library 目录` 和对应的 `--data-dir 目录`。

```sh
mixharness window permissions
mixharness window list
mixharness window bind SESSION_ID TARGET
mixharness window bind SESSION_ID desktop --control
mixharness window status SESSION_ID
mixharness window stop SESSION_ID
```

省略 `--control` 即为「仅查看」。`window permissions screen` 和 `window permissions accessibility` 可分别发起屏幕录制和辅助功能权限请求。

## 隔离验证

`python-compile` 和 `python-tests` 在项目快照中运行。`tests/test_http.py` 和 `tests/test_window_entrypoints.py` 使用独立的会话库、数据目录和系统分配的本地端口。`tests/test_computer_access.py` 验证不同权限下的工具、审批、跨会话拒绝与撤销。`tests/test_window_actions.py` 将操作发给本次测试创建的 AppKit 窗口，并从窗口实际状态核对结果。缺少系统权限时，测试日志会记录跳过的实机项目。
